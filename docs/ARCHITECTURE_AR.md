# قرارات المعمارية

## مصدر الحقيقة والنشر

PostgreSQL هو مصدر حقائق المالك الخاصة. المشاريع والخبرة والتعليم والشهادات واللغات والمهارات مشتركة؛ جداول `profile_*` تنتقي ما يظهر وترتيبه للويب وPDF بصورة مستقلة. الموقع يربط بروفايلًا أو أكثر، وله لغاته ومساراته وSEO وعمليات نشره.

طلب النشر ينشئ `Publication` immutable مع SHA-256 ومفتاح idempotency ومحاولة منفصلة. GitHub Actions يسحب هذه النسخة عبر مسار داخلي محمي، يولّد الموقع وPDF، يشغّل فحوص القبول، ثم يرفع `apps/public/out`. لا يقرأ الموقع المنشور قاعدة البيانات، ولذلك يظل الموقع وPDF متاحين أثناء نوم خدمة الـBackend المجانية.

## العربية والإنجليزية

الترجمات صفوف مستقلة مرتبطة بكل كيان، وليست JSON مبهمًا. يجب وجود اللغتين قبل اعتبار البروفايل صالحًا للنشر. الواجهات تضبط `lang` و`dir`، وتعزل النصوص التقنية المختلطة بـ`bdi`. صفحات كل بروفايل لها canonical مستقل؛ اللغة البديلة تستخدم hreflang عندما توجد النسخة المقابلة.

## الافتراضات التنفيذية

- حساب مالك واحد ولا يوجد تسجيل عام.
- روابط عامة HTTPS فقط؛ localhost للتطوير وحده.
- الهاتف مخفي افتراضيًا، والبريد قابل للعرض وفق سياسة كل بروفايل.
- الخبرة الوظيفية اختيارية؛ القسم الفارغ لا يُعرض ولا يُستبدل ببيانات وهمية.
- `example.invalid` و`*.invalid` بيانات اختبار فقط وتبقى `noindex`.
- الصور اختيارية ولا تمنع إنشاء البروفايل أو PDF.

## القصة التفاعلية للبروفايل العام

مشاهد القصة اختيارية ومترجمة داخل `ResumeProfileTranslation.StoryJson`، وتمر عبر محرر الإدارة والتحقق ونسخة النشر الثابتة إلى الصفحة العامة. البروفايلات بلا قصة تستخدم العرض الحالي. انظر `docs/STORY_EXPERIENCE_AR.md` لمخطط المشاهد وحدود الحقائق المعروضة.

## روابط المشاريع

تُحفظ روابط المشروع المرتبة في `project_links` وتُحرر عبر `GET/PUT /api/v1/admin/projects/{id}/links`. يدعم كل رابط `kind` و`url` وعنوانين اختياريين `labelAr` و`labelEn`؛ النوع `other` يحتاج العنوانين. روابط `repositoryUrl` و`demoUrl` القديمة تظل مدعومة وتُدمج عند العرض دون تكرار الرابط. تقرأ صفحات المشاريع العامة المشاريع المختارة للبروفايل من `GET /api/v1/public/sites/{siteId}/profiles/{profileSlug}/projects?locale=...` بعد الحفظ، وتستخدم لقطة النشر عند تعذر الاتصال. يبقى نشر نسخة جديدة لازمًا لتحديث PDF وبيانات SEO والصفحات الثابتة الأخرى.
