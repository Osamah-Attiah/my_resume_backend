# حالة التنفيذ مقابل مراحل القبول

آخر تحقق محلي: 13 سبتمبر 2026. جميع البيانات الموجودة بيانات `DEMO` صريحة على نطاق `example.invalid`، وليست خبرة أو هوية شخصية حقيقية.

## المكتمل

- المرحلة 1: حل .NET 10، React، PostgreSQL عبر Docker، migrations، CI، إعدادات البيئة، health checks ونسخة demo اختيارية وآمنة.
- المرحلة 2: مصادقة مالك واحد، JWT قصير محفوظ في `sessionStorage` الخاصة بعلامة التبويب ويستمر بعد تحديث الصفحة، إبطال الجلسة، تحديد الملكية، optimistic concurrency، سجل تدقيق، validation وrate limiting.
- المرحلة 3: حقائق مشتركة ثنائية اللغة، مشاريع ونقاط ومهارات وخبرة وتعليم وشهادات ولغات، بروفايلات متعددة وانتقاء وترتيب مستقلان للويب وPDF، ومواقع متعددة تربط بروفايلًا أو أكثر.
- المرحلة 4: PDF عربي وإنجليزي أحادي العمود مناسب لـATS، بخطوط مضمّنة وUnicode، وتصحيح `ActualText` للعربية، وفحوص `pdftotext` و`pdffonts` و`pdfinfo` ورندر PNG.
- المرحلة 5: موقع Next/React مُصدّر إلى ملفات ثابتة بلا اعتماد تشغيلي أو hydration غير مستخدم، RTL/LTR، جوال/كمبيوتر، صفحات مشاريع scoped، 404 حقيقية، canonical/hreflang/JSON-LD/robots/sitemap و`lastmod` مستقر حسب تغير المحتوى، وصور OG عربية/إنجليزية 1200×630 مولدة محليًا لكل بروفايل ومشروع مع اختيار صورة مخصصة وآمنة من مكتبة الوسائط. حقق Lighthouse محليًا 98/100 أداء للعربية و100/100 للإنجليزية، و100/100 لإتاحة الوصول في النسختين.
- المرحلة 6 محليًا: snapshot ثابت، idempotency، محاولات وحالات، rollback، أدلة artifacts وdeployment، منع callback القديم، استرجاع callback المفقود من GitHub artifact، وتصدير PDF خاص من مستودع عمليات خاص بمرجع منتج مثبت.
- المرحلة 7 محليًا: build واختبارات، فحص بصري عربي/إنجليزي، إثبات عمل الموقع وPDF مع توقف API، ماسح أسرار، واختبار فعلي لنسخة PostgreSQL واستعادتها.

## ما يحتاج إجراء المالك

- إنشاء مستودع GitHub للمنتج ومستودع خاص لعمليات PDF، ثم دفع الملفات؛ مجلد العمل الحالي ليس مستودع Git بعد.
- إنشاء وربط Neon وRender وCloudflare Pages وCloudinary المجانية، وإضافة الأسرار المذكورة في `docs/DEPLOYMENT_AR.md`.
- استبدال جميع بيانات `DEMO` بالحقائق الشخصية التي يراجعها المالك قبل أي نشر عام.
- وضع النطاق الحقيقي، تنفيذ أول نشر فعلي، ثم التحقق من روابط الإنتاج وCloudflare deployment وSearch Console. لا توجد نتيجة استضافة خارجية يمكن ادعاؤها دون هذه الحسابات.

نتائج الأوامر والملفات الفعلية موثقة في `docs/QA_RESULTS_AR.md`.
