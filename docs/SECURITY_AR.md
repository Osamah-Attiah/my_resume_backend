# حدود الأمان والخصوصية

- رمز JWT يُحفظ في `sessionStorage` الخاصة بعلامة التبويب حتى لا تضيع الجلسة عند تحديث الصفحة، ولا يُحفظ في `localStorage`. تغيير كلمة المرور والخروج يزيدان `SessionVersion` ويبطلان الجلسات السابقة، وتنتهي الجلسة خلال 30 دقيقة.
- Production يرفض البدء دون `Auth__SigningKey` بطول 32 بايت على الأقل. رسائل الدخول لا تكشف وجود البريد، والمحاولات محدودة، والأخطاء العامة تحمل `traceId` دون stack trace.
- كل استعلام إداري يقيّد الكيان بـ`person_id`. أضيفت مفاتيح FK صريحة لجميع اختيارات البروفايل، المواقع، SEO، المنشورات وartifacts لمنع السجلات اليتيمة.
- الأسرار تدخل من متغيرات البيئة وGitHub Secrets فقط. `.env` والمفاتيح والنسخ الاحتياطية والمخرجات الخاصة مستبعدة من Git، و`npm run test` يشغّل ماسحًا لأنماط الأسرار.
- Snapshot العام يحتوي فقط المواقع والبروفايلات والعناصر المنتقاة. توليد جديد يمسح مخرجات PDF القديمة قبل النسخ، وفحص static يرفض أي PDF زائد عن manifest الحالي.
- PDF الخاص يُبنى في مستودع عمليات خاص من commit منتج مثبت، ويُنزّل عبر API مصادق عليه مع فحص الحجم وترويسة PDF وSHA-256، وينتهي بعد سبعة أيام.
- الصور ترفع مباشرة من API إلى Cloudinary ولا تُحفظ binary في PostgreSQL أو القرص. يقبل PNG/JPEG/WebP حقيقية فقط، حتى 5 MB و6000×6000، مع alt عربي وإنجليزي وSHA deduplication. `Cloudinary__ApiSecret` لا يصل إلى React.
- Callback الداخلي محمي بسر ضيق، والنتيجة لا تقبل artifact بلا SHA-256/حجم/ملكية. رقم المحاولة وrevision يمنعان نتيجة قديمة من استبدال نشر أحدث.
- ملفات PDF العامة تحمل `X-Robots-Tag: noindex`. بيانات `*.invalid` التجريبية تفرض `noindex`، وrobots ليس وسيلة لحماية الأسرار.

قبل جعل المستودع عامًا: شغّل `npm run test`، راجع staged diff يدويًا، وابحث عن بريد أو هاتف أو نطاق حقيقي. لا ترفع `artifacts/` أو `output/` أو dump قاعدة البيانات أو snapshot خاصًا.
