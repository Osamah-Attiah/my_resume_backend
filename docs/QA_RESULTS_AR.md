## البناء والاختبارات

- `dotnet build`: ناجح، 0 تحذيرات و0 أخطاء.
- `dotnet test`: نجح 30 من 30 اختبارًا دون فشل أو تخطٍ؛ تشمل الصلاحيات، الانتقاء وعدم التسرب، بروفايلين على حقائق مشتركة، عزل موقعين، ثبات `lastmod`، مرجع Git المثبت، واسترجاع callback من evidence artifact.
- `dotnet ef migrations has-pending-model-changes`: لا تغييرات معلقة بعد migration `SeoOgAsset`.
- `npm run build`: ناجح على Node.js 24؛ Admin production bundle و12 ناتجًا ثابتًا من Next، تشمل ar/en، البروفايل، المشروع، الأيقونة، 404، robots وsitemap.
- `npm run test`: اختبارا عقد snapshot ناجحان، وماسح الأسرار وفحص static SEO/PDF/OG ناجحان.
- ملفات YAML الأربعة (`ci` و`publish-site` و`render` و`docker-compose`) اجتازت parsing بواسطة Ruby YAML.

## الواجهة والموقع الثابت

- فحص 1280×900 و390×844 للوحة والموقع، بالعربية والإنجليزية، بلا overflow أفقي.
- فُحصت صفحات المواقع/SEO وبروفايلات الموقع، محرر السيرة وPDF الخاص، المشاريع وصورها، والموقع العام. حالات الفراغ والخطأ والتحميل موجودة في المكونات، ورسالة غياب إعداد المستودع الخاص ظهرت بوضوح.
- بدّل الموقع العام `html lang/dir` فعليًا بين `ar/rtl` و`en/ltr`. لا يحمل الناتج JavaScript تنفيذيًا؛ السكربت الوحيد هو JSON-LD، ولم تسجل console أخطاء أو تحذيرات أثناء الجولة.
- يولد البناء 4 صور OG فعلية بصيغة PNG وأبعاد 1200×630 للبروفايل والمشروع باللغتين، مع إمكانية اختيار أصل صورة جاهز ومملوك لصاحب الموقع من لوحة SEO. يرفض API الأصول غير الجاهزة أو غير المملوكة، ويعود التصدير إلى البطاقة المولدة عند عدم الاختيار. فُحصت العربية والإنجليزية بصريًا، ومنها اتجاه `.NET` داخل النص العربي، وتتحقق الاختبارات من رابط الصورة و`summary_large_image` والملف نفسه.
- مع إيقاف API على 5080: `/ar/` أعاد 200 و7,278 bytes، `/en/` أعاد 200 و6,605 bytes، PDF العربي أعاد 200 و70,806 bytes، والإنجليزي 200 و61,523 bytes، وصورة OG العربية ملف PNG صالح بأبعاد 1200×630.

## قاعدة البيانات والنشر

- migration سلامة العلاقات أزال عمود `resume_profile_id` الظلي الفارغ وأضاف FKs الصريحة. كما أضاف migration `SeoOgAsset` فهرسًا وعلاقة `SET NULL` بين تخصيص SEO وأصل صورة المشاركة؛ لا تبقى صورة معلقة إذا حُذف الأصل.
- اختبار callback محلي سابق لنشر immutable سجّل publication وattempt و3 artifacts وSiteDeployment واحد، وكرر callback دون duplicate.
- اختبارات الاسترجاع تحاكي GitHub run ناجحًا وartifact ZIP، وتعيد `AttemptResult`، كما تحول conclusion فاشلة إلى حالة terminal فاشلة.
- اختبار النسخ والاستعادة النهائي استعاد dump في قاعدة مؤقتة وقرأ: 6 migrations، شخص واحد، بروفايل واحد، موقع واحد، 8 publications، 3 artifacts و0 media assets. أكد وجود 4 علاقات FK في `seo_page_settings`، منها علاقة `og_asset_id` الجديدة، ثم حُذفت قاعدة الاختبار وملف dump المؤقتان.

## ما لم يمكن اختباره محليًا

لا يوجد مستودع Git أو حسابات/أسرار Neon وRender وCloudflare وCloudinary أو نطاق حقيقي في مساحة العمل. لذلك لم يحدث deploy خارجي، رفع صورة فعلي، تحقق Search Console أو smoke test لنطاق إنتاج. الكود وملفات النشر جاهزة، لكن هذه نتائج خارجية لا يصح ادعاؤها قبل أن يوفرها المالك.
