# توليد وفحص PDF

يستخدم الملف النهائي QuestPDF مع خطوط Cairo مضمّنة وقالب أحادي العمود. تُحفظ معاينة HTML منفصلة لتسهيل تحرير القالب، لكنها ليست دليل قبول للملف النهائي.

## لماذا توجد خطوة تصحيح ActualText؟

اختبار مبكر لـChromium أظهر أن الشكل العربي قد يكون صحيحًا بصريًا بينما يخرج `pdftotext` ترتيبًا تالفًا. بعد توليد QuestPDF تمر المقاطع العربية متعددة المحارف في `normalize_actual_text.py` لتصحيح طبقة `/ActualText` فقط؛ الرسوم المرئية لا تتغير. هذه الخطوة جزء من خط البناء وليست معالجة يدوية بعد النشر.

## معايير القبول الآلية

- استخراج الاسم والمسمى وأول عناصر فعلية من snapshot نفسه، لا قائمة ثابتة.
- عدم وجود Unicode presentation forms أو رمز الاستبدال `�`.
- خطوط مضمّنة مع Unicode mapping وفق `pdffonts`.
- A4/Letter وعدد الصفحات لا يتجاوز إعداد البروفايل.
- حجم كل ملف أقل من 2MB.
- رندر PNG بواسطة Poppler للفحص البصري النهائي.

شغّل:

```bash
npm run pdf:generate
npm run pdf:qa
```

تقارير JSON وصور الصفحات تُنشأ تحت `artifacts/pdf-qa/`، والنسخ الجاهزة محليًا تحت `output/pdf/`. المجلدان غير متعقبين لتجنب نشر سيرة خاصة بالخطأ.
